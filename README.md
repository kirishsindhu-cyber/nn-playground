# Interactive Neural Network Playground
Web-based demo (TensorFlow + Streamlit) to see how a neural network learns. Choose a dataset, layers, neurons, activation and learning rate, then watch the decision boundary and loss curves update live.

**Run locally**
```
pip install -r requirements.txt
streamlit run app.py
```
**Deploy:** push to GitHub, then create an app at share.streamlit.io pointing to `app.py`.
